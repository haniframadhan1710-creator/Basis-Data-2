Pengambilan dan Penyaringan DataNilai Unik (DISTINCT): Perintah SELECT DISTINCT digunakan untuk menampilkan nilai-nilai yang unik dari sebuah kolom, sehingga data yang duplikat tidak akan muncul dalam hasil pencarian.  Pengurutan Data (ORDER BY ASC): Untuk menyusun data secara alfabetis atau urutan angka terkecil ke terbesar (menaik), digunakan perintah ORDER BY [nama_kolom] ASC.  Fungsi Agregasi dan Pengelompokan: Laporan menunjukkan penggunaan fungsi AVG() untuk menghitung rata-rata harga secara spesifik berdasarkan kelompok kategori tertentu menggunakan perintah GROUP BY.
2. Pembaruan Data (Update) Perintah UPDATE digunakan untuk mengubah data yang sudah ada di dalam tabel secara spesifik melalui klausa WHERE agar tidak mengubah seluruh isi tabel. Beberapa skenario yang dipraktikkan meliputi: Satu Kolom: Memperbarui satu nilai (misalnya stok barang) berdasarkan ID tertentu. Beberapa Kolom: Mengubah nama dan stok sekaligus dalam satu perintah query. Data Spesifik: Mengubah informasi alamat karyawan dengan merujuk pada ID karyawan tersebut.
